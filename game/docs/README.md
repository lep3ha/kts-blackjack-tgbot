# Game Service Docs

Документация для микросервиса `game` (HTTP API и бизнес-логика blackjack).

## Что делает сервис

- управляет состоянием игровых сессий (single/group)
- применяет правила blackjack и рассчитывает выплаты
- предоставляет HTTP API для `router`

## Карта документации

- `service_overview.md` — назначение сервиса, границы ответственности, слои и интеграции.
- `api.md` — HTTP-эндпоинты, схемы запросов/ответов, ошибки.
- `game_logic.md` — правила раунда, действия игрока, поведение дилера.
- `state_machine.md` — жизненный цикл сессии, события и переходы.
- `entities.md` — доменные и ORM-сущности.
- `blackjack_architecture.md` — внутренняя архитектура и поток данных.

## Связанные файлы

- `../README.md` — запуск и разработка game-сервиса.
- `../alembic/` — миграции схемы БД.
- `../docker/init-db/init.sql` — инициализация Postgres при старте контейнера.
