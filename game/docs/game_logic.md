# Игровая Логика Blackjack

## Область Ответственности
Этот сервис реализует сценарий одного раунда blackjack для заранее созданной игровой сессии.

Поддерживаемые действия:
- `hit`
- `stand`
- `double`

Неподдерживаемые механики:
- `split`
- `insurance`
- дополнительные правила surrender

## Карты И Подсчет Очков
- Формат карты: `<RANK><SUIT>`, например `AS`, `10H`, `7D`.
- Ранги: `A, 2..10, J, Q, K`.
- Масти: `S, H, D, C`.
- Правила подсчета:
1. Числовые карты дают количество очков по номиналу.
2. `J/Q/K` дают `10` очков.
3. `A` изначально считается как `1`, затем может быть повышен до `11`, если это не ведет к перебору.

Натуральный blackjack фиксируется только при двух картах и сумме `21`.

## Ход Раунда
1. Сессия создается в `lobby_open` (persisted `SessionStatus`).
2. `start` раздает по две карты каждому сидящему игроку и две карты дилеру.
3. Сервис выбирает первую игровую позицию (`score < 21` и не натуральный blackjack).
4. В фазе игрока обрабатываются `hit`, `stand`, `double` или timeout.
5. Когда все игровые позиции завершили ход, дилер добирает карты до суммы не меньше `17`.
6. На этапе settlement считаются дельты и сессия закрывается.

Примечание по статусам:
- persisted `SessionStatus` — это внешний жизненный цикл (`lobby_open/in_progress/stopped/closed`).
- runtime state machine state — это фаза раунда (`waiting/dealing/player_turn/dealer_turn/resolving/closed`).

## Правила Действий Игрока
- `hit`: взять ровно одну карту.
  - Если итоговый счет `< 21`, ход остается у текущего игрока.
  - Если итоговый счет `>= 21`, ход передается дальше.
- `stand`: карта не берется, ход передается дальше.
- `double`:
  - Разрешен только на первых двух картах.
  - Требует `player.bank >= 2 * current_bet`.
  - Ставка удваивается, берется одна карта, после чего рука автоматически завершает ход.

## Правила Timeout
- Timeout допустим только для текущей активной позиции.
- Timeout принимается только после истечения `current_timer`.
- Timeout завершает текущую руку и передает ход аналогично `stand`.

## Правила Дилера
- Дилер добирает карты, пока счет `< 17`.
- На `17+` дилер останавливается.

## Правила Settlement
Для каждого игрока при ставке `bet`:
1. У игрока натуральный blackjack, у дилера нет: `delta = floor(1.5 * bet)`.
2. Игрок перебрал: `delta = -bet`.
3. Дилер перебрал, игрок нет: `delta = +bet`.
4. Счет игрока больше счета дилера: `delta = +bet`.
5. Равные счета: `delta = 0` (`push`).
6. Во всех остальных случаях: `delta = -bet`.

Баланс игрока обновляется сразу на этапе settlement, после чего сессия переходит в `closed`.

## Примечания По Хранению
- Поля уровня сессии (`status`, `current_position`, `current_timer`, `dealer_cards`) хранятся в `game_sessions`.
- Поля уровня места (`cards`, `bet`) хранятся в `player_to_session`.
- Каждый значимый шаг пишется в `states` для аудита и отладки (`deal`, `hit`, `stand`, `double`, `timeout`, `dealer_hit`, `result`, `session_closed`).
